## Description

This project demonstrates JavaScript ES6 features, Promises, and Node.js file system operations.

## Question 1 – ES6 Features

The `lowerCaseWords()` function accepts a mixed array, filters out non-string values, converts the remaining strings to lowercase, and returns a Promise.

**Run:**
`node question1/lowerCaseWords.js`

## Question 2 – Promises

The `resolvedPromise()` function resolves a success message after 500 milliseconds.

The `rejectedPromise()` function rejects an error message after 500 milliseconds.

Both outcomes are handled using `.then()` and `.catch()`.

**Run:**
`node question2/promises.js`

## Question 3 – File Module

Uses the Node.js `fs` and `path` modules.

- `add.js` creates a Logs directory and generates 10 text files.
- `remove.js` deletes the log files and removes the Logs directory.

**Run:**

`node question3/add.js`

`node question3/remove.js`
